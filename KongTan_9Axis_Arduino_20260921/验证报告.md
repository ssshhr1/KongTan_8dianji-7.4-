# 验证记录

日期：2026-09-21。对象：本目录独立 Arduino 九轴版本，不是原八轴项目。

## 已完成

- 最终源码的 Windows x64 Debug、Release 编译均成功，包含零位移不动作处理；Release EXE 为 309248 bytes，Debug EXE 为 775680 bytes。
- 30 组离线测试通过，结果见 `tests/test-results.txt`。测试包含三段分组、完整目标校验、分段限幅、慢轴到位屏障、旧完成状态、正反向终点、下发部分失败、反馈丢失、超时、启动回滚、CRC、重复序号、整数溢出、固件速度/加速度限制、看门狗、停止、脉冲间隔、计时回绕与规划滞后。
- 固件核心 `FeedCore.h` 是实际 `.ino` 引用的同一份实现，已由本机 C++ 离线测试执行。
- 默认 `Confirmed=0`、未知 COM、脉冲换算及限位为 0，阻止 PC 连接；固件 `WIRING_CONFIRMED=false`、引脚 -1，阻止运动输出。
- 保留了原工程已有未提交修改和旧 CAN 九轴版本。

- Mega 2560 原生编译通过：FQBN `arduino:avr:mega:cpu=atmega2560`，Arduino AVR core 1.8.8，CLI 1.5.2-rc.1。Sketch 占用 9886 bytes Flash（3%）、524 bytes SRAM（6%），编译的是接线未确认、禁止输出的默认配置。日志见 `build-firmware.log`。

## 构建警告

现有第三方 `CML.lib` 包含 `/GL` 模块，链接器切换 LTCG；Debug 还报告增量链接/运行库冲突警告；厂商 PDB 缺失产生 LNK4099。构建成功不代表这些第三方库的全部运行行为经过验证。本次未更换厂商库。AVR `--warnings all` 还报告 Arduino 核心 new.cpp 的 unused parameter tag 警告，未发现本项目固件源文件编译错误。
